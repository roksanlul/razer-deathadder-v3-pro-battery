# Razer DeathAdder V3 Pro Battery (Windows)

Лёгкое приложение на Zig показывает заряд Razer DeathAdder V3 Pro в системном
трее Windows. Работает с беспроводным HyperSpeed-приёмником и при проводном
подключении.

## Возможности

- Значок батареи меняет цвет: зелёный — больше 40%, жёлтый — 21–40%, красный —
  20% или меньше.
- Во время зарядки значок жёлтый и показывает молнию.
- При уровне 20% или ниже Windows показывает предупреждение, если мышь не
  заряжается. Повторное предупреждение появится после начала зарядки или когда
  уровень поднимется выше 20%.
- Заряд опрашивается каждые 30 секунд. Для немедленного опроса выберите
  **Refresh now** в контекстном меню значка.
- Одновременно работает только один экземпляр: повторный запуск тихо
  завершается.
- Если беспроводная мышь уснула, последнее полученное значение сохраняется на
  значке до пяти минут и помечается как **last seen**.

## Установка

1. Скачайте `razer-battery-menu-tray.exe` из раздела
   [Releases](../../releases/latest).
2. Запустите файл и найдите значок батареи рядом с часами. Если значок скрыт,
   проверьте меню скрытых значков Windows.
3. Наведите курсор на значок, чтобы увидеть заряд. Нажмите правой кнопкой мыши
   для обновления или выхода.

Приложение не подписано цифровой подписью; Windows может показать стандартное
предупреждение SmartScreen.

## Сборка из исходников

Требуется Zig **0.14.1** для Windows x64 и доступ в интернет. Скрипт `build.ps1`
скачивает исходники HIDAPI 0.14.0, проверяет SHA-256 архива, запускает тесты и
собирает автономный EXE:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

Для запуска только тестов:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -TestOnly
```

Результат сборки: `razer-battery-menu-tray.exe`.

## Устранение неполадок

- Разбудите мышь движением или нажатием кнопки и выберите **Refresh now**.
- Если вместо заряда показывается **battery not found**, закройте Razer Synapse
  и повторите обновление.
- Убедитесь, что HyperSpeed-приёмник подключён и мышь связана с ним.

Приложение не меняет настройки мыши и не отправляет данные в сеть. Сеть нужна
только скрипту сборки для загрузки исходников HIDAPI.

## Сторонний компонент

Для USB HID используется [HIDAPI 0.14.0](https://github.com/libusb/hidapi) под
исходной лицензией; уведомление находится в [LICENSE-hidapi.txt](LICENSE-hidapi.txt).
