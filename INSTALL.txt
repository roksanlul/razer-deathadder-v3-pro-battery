Установка
=========

1. Скачайте razer-battery-menu-tray.exe из GitHub Releases.
2. Запустите файл.
3. Наведите курсор на значок батареи рядом с часами — появится процент.
4. Нажмите правой кнопкой по значку, чтобы обновить заряд или закрыть приложение.

Индикатор: зелёный — заряд выше 40%, жёлтый — 21–40%, красный — 20% или ниже.
Во время зарядки значок жёлтый с молнией. При заряде 20% или ниже Windows
показывает предупреждение, если мышь не подключена к зарядке.

Приложение обновляет показания каждые 30 секунд. Если мышь уснула, последнее
значение показывается ещё до пяти минут с пометкой "last seen".

Полная документация и сборка из исходников: README.md.
